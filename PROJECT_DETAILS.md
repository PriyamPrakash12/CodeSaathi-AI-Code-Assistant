## Project Information
- **Project Title:** CodeSaathi — AI Code Assistant
- **Domain:** Generative AI, Prompt Engineering, Web Development
- **Tech Stack:** Python (Flask), Gemini API, HTML/CSS/JavaScript
- **One-line description:** A browser-based AI coding assistant with four modes — Explain, Generate, Fix, and Refactor — built to demonstrate prompt engineering techniques (role prompting, few-shot examples, chain-of-thought, structured JSON output, and goal-directed constraints).

### Key Features
- **Explain mode** — breaks down code for beginner/intermediate/expert audiences
- **Generate mode** — writes code from a plain-English description
- **Fix mode** — diagnoses and corrects code given an error message
- **Refactor mode** — improves code toward a stated goal, with reasoning for each change

### Prompt Engineering Techniques Demonstrated
- Role prompting (system prompt sets a consistent persona)
- Few-shot prompting (Generate mode)
- Chain-of-thought instructions (Explain mode)
- Error-grounded prompting (Fix mode)
- Goal-directed constraints (Refactor mode)
- Structured JSON output parsing across all modes
